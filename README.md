# Borsha Web — Premium Real Estate Website

Seven-page responsive real-estate website inspired by the supplied visual reference: dark/navy luxury palette, warm-gold accents, large property hero, floating search panel, property cards, trust blocks, CTA and premium footer.

## Public pages
- Home
- Properties
- Property details
- About
- Services
- Blog
- Contact

`admin.html` is an additional non-public dashboard page for future backend integration.

## Run
Open `index.html` directly, or serve the folder with any static server. For Cloudflare Pages/Workers Static Assets, the included `wrangler.toml` points assets to the repository root.

## Notes
- No database required.
- Forms are demo/client-side only.
- Property data is in `app.js` for easy editing.
- Brand/sponsor text is **Borsha Web / Made by Borsha Web**.
